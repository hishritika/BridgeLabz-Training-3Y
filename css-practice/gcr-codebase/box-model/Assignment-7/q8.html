CSS Box Model

Understanding Content, Padding, Border and Margin

Box Model Layers

MARGIN
BORDER
PADDING
CONTENT

Content

The content area contains the actual text, images or other information inside an element.

Padding

Padding creates space between the content and the element's border.

Border

The border surrounds the padding and content and can have different widths and styles.

Margin

Margin creates space outside the border and separates the element from other elements.

Box-Sizing Comparison

content-box

200px Width

With content-box, the declared width applies only to the content area. Padding and border are added to the total size.

border-box

200px Width

With border-box, the declared width includes the content, padding and border.
