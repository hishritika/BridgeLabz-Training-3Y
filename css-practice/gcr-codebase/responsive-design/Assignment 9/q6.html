Responsive CSS Cheat Sheet

Filters

CSS filters can change the appearance of an element.

filter: grayscale(100%);

Media Queries

Media queries change the layout according to the screen size.

@media (max-width: 700px)

Responsive Design

Responsive design makes a webpage work properly on different screen sizes.

width: 100%;

Typography

Responsive typography allows text to adjust according to the screen size.

font-size: clamp(1rem, 2vw, 1.5rem);
